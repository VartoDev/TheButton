# The Button

A simple web game made with Flask, HTML, CSS and JavaScript.

## About

The Button is a game where your goal is to reach the highest click streak possible.

Every time you click the button, the chance of losing your progress increases. One unlucky click will reset your streak back to 0.

Can you reach the highest score?

## Features

- Increasing difficulty
- Highscore system
- Sound effects
- Simple and clean interface
- Built with Flask API requests

## Technologies

- Python
- Flask
- HTML
- JavaScript

## Installation

1. Clone the repository.

```bash
git clone https://github.com/YOUR_USERNAME/TheButton.git
```

2. Install Flask.

```bash
pip install Flask
```

3. Start the application.

```bash
python app.py
```

4. Open your browser and go to:

```
http://127.0.0.1:5000
```
